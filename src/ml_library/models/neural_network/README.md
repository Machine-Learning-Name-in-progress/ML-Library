# File Responsibilities

| File | Responsibility|
|---|---|
| `activations.py` | Implements activation functions and their derivatives, such as ReLU, sigmoid, and tanh. |
| `layers.py` | Defines neural network layers, including parameter initialization, forward propagation, and gradient computation during backpropagation. |
| `losses.py` | Implements loss functions and their derivatives, including Mean Squared Error (MSE) for regression. |
| `mlp.py` | Defines the MLP model, manages the network architecture, and coordinates forward propagation, backpropagation, and training. |
| `optimizers.py` | Implements optimization algorithms responsible for updating model parameters using computed gradients. |
| `__init__.py` | Defines the public interface of the neural network package. |
